Política de privacidad

Control Skin Care · actualizada el 20 de noviembre de 2026

Qué es

Control Skin Care es un programa de escritorio para Windows de uso privado. Lo usan solo los dueños del negocio, en su propia computadora.

Qué datos de Google usa

Con el permiso de solo lectura de Gmail (gmail.readonly), el programa busca únicamente los correos enviados por autoreply@yesstyle.com y lee de ellos números de pedido, productos, precios, cobros, reembolsos y envíos. No lee otros correos con otro fin, y nunca envía, modifica ni borra correos.

Dónde se guardan

Todo se guarda solo en la computadora donde está instalado el programa. Los datos de acceso de Google se guardan cifrados con la protección de Windows. Ningún dato se envía a servidores propios ni a terceros, y no se usa para publicidad.

Cómo quitar el acceso

Puedes quitar el permiso cuando quieras desde myaccount.google.com/permissions o con el botón “Quitar” del programa. Desinstalar el programa y borrar la carpeta %APPDATA%\Control Skin Care elimina todos los datos.

Uso de datos de Google

El uso de la información recibida de las API de Google cumple con la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Contacto

Para cualquier pregunta, escribe al correo de asistencia que aparece en la pantalla de permisos de Google de esta app.
